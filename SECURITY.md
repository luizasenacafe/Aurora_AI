# Security reporting

Do not post credentials, conversations, or exploitable details in public issues. Use GitHub private vulnerability reporting if enabled. Otherwise, open a minimal issue requesting a private contact channel without disclosing the vulnerability.

There is no guaranteed response-time SLA. This is an individual-maintained prototype. Read [Privacy](docs/PRIVACY.md) before deploying. Rotate exposed keys in the server panel; removing them from a file does not revoke them.
