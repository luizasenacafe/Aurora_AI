# Betelgeuse Python applications

The current Windows desktop client lives in `source/`; the self-hosted gateway and local control panel live in `server/`.

See [Getting started](../docs/GETTING_STARTED.md), [Architecture](../docs/ARCHITECTURE.md), and [Privacy](../docs/PRIVACY.md) for English setup and operational documentation.

The historic Aurora module, environment-variable, database, and protocol names are retained for compatibility. Windows executables are available from repository Releases. The product UI remains primarily Brazilian Portuguese.
