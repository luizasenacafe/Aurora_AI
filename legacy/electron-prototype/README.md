# Original Aurora Electron prototype

Preserved historical React, TypeScript, Vite, and Electron implementation. Chat responses are simulated. This is not the current Betelgeuse application; start at the [main README](../../README.md).

Historical commands, from this directory:

```sh
npm install
npm run dev
npm run electron:dev
```

Build commands: `npm run electron:build` and `npm run electron:pack`. Dependencies and builds in this archive were not refreshed or validated in the current update. Aurora branding is retained for provenance.
